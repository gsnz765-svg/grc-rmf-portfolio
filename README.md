# GRC / RMF Portfolio — Gabriela Sanchez Ramirez

Army veteran and cybersecurity student (B.S. IST, Cybersecurity, CSUSB, Dec 2026)
building hands-on Governance, Risk, and Compliance (GRC) work aligned to the
NIST Risk Management Framework (RMF).

**Goal:** Take one system through the full RMF lifecycle — Categorize, Select,
Implement, Assess, Authorize, Monitor — and produce the artifacts an
Information System Security Officer (ISSO) maintains.

## The Scenario
**Organization:** Inland Valley Veterans Services Office (IVVSO), a fictional
state agency that helps veterans access benefits.

**System:** IVVSO Log Monitoring System (LMS), an Ubuntu Server virtual machine
running Splunk to collect and review security logs.

> All organizations, systems, and data in this repository are fictional and
> built in a personal home lab. No real or sensitive data is used.
